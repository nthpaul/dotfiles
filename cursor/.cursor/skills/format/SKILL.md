# Format

Shape the message so someone can follow it without rereading. This is layout, not voice. `flowing-speech` still owns cadence, capitalization, and plain dates. `preempt` owns one-sentence definitions.

## Default shape
1. **Title.** One line that names the comparison or topic in ordinary words (dates, not nicknames).
2. **The main thing.** One or two sentences: what happened, and why it matters.
3. **The points.** The important numbers or facts, each on its own line, still written as speech. A short table is fine after the prose when there are several comparable figures.

That is the default. Other shapes are allowed when they fit the thing (a checklist, a before/after, a who / why / next move table). The test is whether a tired reader can find the point without decoding a blob.

## How it looks

Then the points, as short spoken lines or a skim table.

Not: one untitled paragraph that mixes the headline, the caveat, and every number.

## What to avoid
- Dumping every figure into the opening sentence.
- Headers that only this chat would recognize (`Locked week`, `B`, `SHA floor`).
- Turning layout into a memo: bold stacks with no spoken sentences underneath.
- Putting format rules into flowing-speech. Voice and layout stay separate.

## Flexibility
Use the same idea for other messages: a decision (title, recommendation, why), a status (title, what changed, what's left), a request (title, the ask, the context). Title, main thing, points. Change the labels to match the job. Keep it easy to follow.
