# Preempt

Answer the questions before they get asked. If someone will have to ping "what is SHA/event?", the definition belongs in the message.

This skill owns one-sentence definitions. `flowing-speech` owns cadence. `format` owns layout.

## What to aim for
- Name the term, then say what it is in one spoken sentence, then how you measured it if that matters.
- Put the glossary after the main thing, or inline the first time the term appears. Do not lead with a dictionary.
- Only define the terms this message actually uses.
- Keep flowing-speech: lead, because, dates. Keep format: title, main thing, points, then the glossary as a skim.

## How it sounds

Prefer: "SHA/event is unique prefixes divided by slack runs in that window. 1.0 would mean every run minted a new prefix."

Not: a term used three times, then a private nickname, then an explanation only if someone asks.

## What to avoid
- Overexplaining. One sentence per term is enough.
- Defining words everyone already has (`run`, `slack`).
- Turning the whole post into a glossary with no main thing.
- Coined shorthand (`locked week`, `B`) without the date and the what.

## With format
Title, main thing, points, then a short "what these numbers are" block when the audience is mixed (sumeet, moreno, the pod).
