# Reference fixture

The `injury-rtw` example reconstructs the Injury & return-to-work plan created on
October 8, 2026 from the linked PRD and Traba source revision `c60d232e91`.
Its original published artifact is
[the Relay build plan](https://relay.traba.work/library/paul/injury-rtw/build-plan.html).
The original HTML SHA-256 is
`8c5c4f7c41070e8bcec01b7d2edb268d99e958d23b5132e31a67f7d0968eaffa`.

The workflow was verified from visible user/assistant/tool history and construction
scripts, then rebuilt in isolation. The fixture contains authored model, flow and
prototype inputs rather than a copied final HTML or SVG screenshot. Its manifest
records the normalized model hash, canonical DOT hashes and expected interactions.
Private model analysis is not part of the package or evidence.

The reusable workflow preserves the source-grounded planning, shared demo state,
Graphviz SVG rendering, editable diagram sources, Poppins/Traba styling and single-file
delivery. The package adds capability detection, one-command generation, a generic
viewer, standalone guidance, automatic Markdown composition, dark theme and a narrow
phone-layout fix. Consequently, its final HTML differs from the original bytes while
retaining the reference model, diagram content and connected behavior.

The original fixture's reuse findings describe the inspected October 8 checkout.
Refresh evidence before treating them as a plan for a newer code revision. Worker-app
screens were proposed because its mobile source was unavailable in that investigation.
